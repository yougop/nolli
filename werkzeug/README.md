# Nolli web app

The Nolli tool itself: a SvelteKit app built as a static site. See the
[README in the repository root](../README.md) for what it does, the package
it writes and how to use it.

```bash
npm install
npm run dev -- --open     # development
npm run build             # static site in build/
npm run check             # type checking
```

`starten.sh` installs on first run and starts the dev server on port 5177.
